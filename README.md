# 声之回响 · 虚拟歌姬翻唱作品展示平台

一个纯静态的虚拟歌姬翻唱作品展示网站，汇集洛天依、乐正绫、言和、心华、初音未来、星尘等虚拟歌姬的翻唱作品，支持搜索、按歌姬/曲风筛选、排序、收藏，并提供 B 站 / 网易云 / YouTube 的收听入口。

## 功能

- 🎵 作品卡片展示：自动生成渐变封面、歌姬标签、曲风标签、播放/收藏数据
- 🔍 实时搜索：支持作品名、原曲、原唱、歌姬、曲风
- 🎚 筛选与排序：按歌姬、曲风筛选；按最新 / 播放 / 收藏排序
- ❤️ 收藏：本地保存（localStorage），无需后端
- 🔗 一键收听：每首作品提供 B 站、网易云、YouTube 搜索入口
- 📱 响应式布局：手机 / 平板 / 桌面自适应

## 本地运行

项目为纯静态页面，无需安装依赖。直接双击 `index.html` 即可打开，或使用任意静态服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 如何添加作品

打开 `js/data.js`，在 `window.VS_SONGS` 数组末尾追加一个对象即可：

```js
{
  id: "my_song",           // 唯一 ID（英文/数字/下划线）
  title: "作品名",
  original: "原曲名",
  originalArtist: "原唱",
  singer: "luotianyi",     // 歌姬 key，见 VS_SINGERS；新歌姬需在 VS_SINGERS 中注册配色
  genre: ["流行", "古风"], // 曲风标签
  year: 2026,
  duration: "04:00",
  views: 10000,            // 播放量
  likes: 500,              // 收藏量
  desc: "一句话作品简介"
}
```

保存后刷新页面即可生效。

## 技术栈

- 原生 HTML / CSS / JavaScript，无任何框架与构建步骤
- 封面由 JS 动态生成内联 SVG，仓库不依赖外部图片资源
- 所有音视频链接均为外部平台搜索入口，本站不存储任何音视频内容
